# Changelog

All notable changes to Roman Nepali Keyboard will be documented in this file.

## [1.0.0] - 2026-09-02

### Added
- Initial release
- QWERTY keyboard with Roman Nepali mapping
- Smart word suggestions using Trie + N-gram model
- Autocorrect functionality
- Next-word prediction
- Emoji keyboard with 250+ emojis
- 5 built-in themes (Dark, Light, Nepali Flag, Ocean, Forest)
- Settings app with preferences
- Text editing mode (cursor control, copy/paste)
- Clipboard manager
- Symbol keyboard
- Long-press shortcuts
- 1000+ Roman Nepali words in dictionary
- Bigram frequency data for predictions
- Haptic feedback on keypress
- Auto-capitalization
- Double-space period
- One-hand mode
- Key preview popups
- Swipe to delete word

### Technical
- Built with Kotlin
- Uses Android InputMethodService
- Trie data structure for fast prefix matching
- N-gram model for word pair prediction
- Material Design components
- No internet permission required
- 100% offline functionality
- No tracking or analytics
